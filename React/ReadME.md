# React
This section of the curriculum focuses on learning React, a popular JavaScript library for building user interfaces. The curriculum is designed from the basics of React to more advanced concepts, including state management, hooks, and building complex applications.

### Learning Path
This folder contains the fundamentals learning path, which includes projects and exercises focused on:

- Introduction
- Getting Started with React
- State and Effects
- Class Components
- React Testing
- The React Ecosystem
- More React Concepts

### Folder Structure
- Exercises/: Contains exercises that reinforce the concepts learned in the curriculum.
- Projects/: Contains larger projects that integrate multiple skills.
- Notes/: Contains notes and resources related to the curriculum.
